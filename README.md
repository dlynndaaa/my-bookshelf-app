A clean and interactive mobile application built with React Native and Expo Router to help users manage their personal book collections and track reading progress.

This project focuses on implementing a modern, space-efficient UI and essential CRUD (Create, Read, Update, Delete) functionalities, transitioning from standard template layouts to a clean, full-screen mobile experience.

## 🚀 Key Features Demonstrated
- **Side-by-Side Layout:** A modern book card design displaying the cover image alongside book details for better space efficiency.
- **Interactive Progress Bar:** Easily update reading progress using intuitive `-` and `+` buttons instead of manual typing.
- **Custom Book Covers:** Integration with `expo-image-picker` allowing users to upload personalized book covers directly from their device gallery.
- **Full CRUD Functionality:** Add new books, edit existing information, update pages read, and delete books from the collection.
- **Clean Navigation:** Distraction-free, full-screen UI completely cleared of unnecessary default Expo tabs and floating settings icons.

## 💻 Local Setup
To run this project locally on your machine:
1. Clone this repository:
   ```bash
   git clone https://github.com/dlynndaaa/my-bookshelf-app.git
2. Install dependencies:
   ```bash
   npm install
3. Start the Expo development server (with cleared cache):
   ```bash
   npx expo start -c
4. Scan the QR code using the Expo Go app on your physical device.
